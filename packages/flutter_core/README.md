# flutter_core

Shared application core package for Foodily Flutter apps.

## Includes

- Theme and design tokens (`FoodilyTheme`)
- Shared domain models and enums
- Localization helpers (English/Hindi seed)
- Network API client with backend-first + fallback behavior
- Mock data for offline/demo scenarios

## Usage

Add as a local path dependency from app packages and import:

```dart
import 'package:flutter_core/flutter_core.dart';
```
